# NBS WORKATION

開催回ごとにアンケートを作成し、Webで回答を集め、集計結果をExcelに出力するアプリです。

## 現在の状態

Windowsのローカル環境で動作確認するための版です。**AWS公開・Docker対応は未実装です。**
起動スクリプトとExcel出力は、WindowsにインストールされたCodexの実行環境に依存します。
このリポジトリを取得するだけで、一般のPCやAWSでそのまま起動できる状態ではありません。

## 機能

- 管理者ID・パスワードによるログイン
- 開催情報の登録、開催日順の一覧、開催月での絞り込み
- 開催回ごとの回答URLと受付開始・終了の管理
- 全16問のアンケート回答、確認、送信と途中入力のブラウザー保存
- 開催回ごとの集計、回答原文の確認、Excel・JSON出力
- SQLiteによる開催情報・回答の保存

参加者はログインせずに回答できます。同じURLを複数人で利用できますが、同一人物の複数回回答を完全に防ぐ機能はありません。
AIや外部AI APIは、アンケート受付・集計には使用しません。

## このPCでの起動

1. Codexの実行環境が利用できるWindowsで `start.cmd` を実行します。
2. 管理画面 `http://localhost:8765/admin` を開きます。
3. 初回に管理者IDとパスワードを設定し、開催回を作成します。
4. 利用者向け一覧は `http://localhost:8765/` です。
5. 終了時は `stop.cmd` を実行します。

`localhost` は起動しているPC自身を指します。他の参加者へこのURLを配布してもアクセスできません。
詳しい操作・集計方法は [使い方.txt](使い方.txt) を参照してください。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `server.py` | Web配信、回答受付、管理者認証、集計、DB処理 |
| `schema.json` | 設問・選択肢のひな形 |
| `public/` | 利用者画面、管理者画面、スタイル |
| `export.mjs` | 集計Excelの生成 |
| `start.cmd` / `start.ps1` | Windowsでの起動 |
| `stop.cmd` / `stop.ps1` | Windowsでの停止 |

## データの扱い

回答・開催情報・管理者の認証情報は `data/survey.sqlite3` に保存します。
`data/`、ログ、環境設定、依存ライブラリー、出力Excel、ローカルの画面画像はGitの管理対象外です。
GitHubへプッシュしても、これらのデータのバックアップにはなりません。
DB全体のバックアップは、アプリを停止してから `data/` フォルダーをコピーしてください。
管理画面から出力するJSONは、選択した開催回の情報と回答を保存するものです。

## AWSに配置するまでの準備

- Codexのインストールに依存しない実行環境・Excel生成環境への変更
- Dockerfileと起動設定の作成、ローカルでのDocker動作確認
- 本番用Webサーバー、公開ホスト名、HTTPS、管理者認証の設定
- コンテナとは分けたDBの永続保存と、別の保存先へのバックアップ
- AWS上での回答登録・認証・Excel出力・再起動後のデータ保持の確認

GitHubへの保存とAWSへの公開は別の作業です。
